# Atronic Photos updates

This folder holds everything Atronic Photos (Android) needs to update itself: the two newest
`Atronic-Photos-update-N.apk` files and `version.json` (name, size, url, sha256 of the newest one).

It is written by the "Build and publish" workflow of the Atronic-Photos source repository on every push to main.
The first published version is 2.1. No update has been published yet.
