# Atronic Updates

Release builds and update feeds for Atronic Systems apps. Source code lives in each app's own repository.

| Folder | App | Source |
|---|---|---|
| `GPS/` | Atronic Speed (Android) | https://github.com/Skisfa99/Atronic-Speed |
| `tools/` | Atronic Tools and ARC Server (Windows and Android) | https://github.com/Skisfa99/Atronic-Tools |

Each app folder holds the current build files and a `version.json`; the apps read their folder on launch to offer updates.
