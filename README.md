# Atronic Updates

Release builds and update feeds for Atronic Systems apps. Source code lives in each app's own repository.

| Folder | App | Source |
|---|---|---|
| `GPS/` | Atronic GPS (Android) | https://github.com/Skisfa99/Atronic-GPS |

Each app folder holds the current APK and a `version.json` that the app reads on launch to offer updates.
